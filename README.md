# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリとはオンラインで同時に開発状況を共有可能なもの。ローカルリポジトリは個人のPC上で開発状況を管理するもの。

## プッシュとマージの違いは何でしょうか？

- プッシュはローカルリポジトリの変更内容をリモートに取り込むこと。マージはブランチの変更内容をマスターに取り込むこと。

## コミットとプッシュの違い

- コミットはローカルリポジトリ内に保存すること、プッシュはローカルリポジトリの変更内容をリモートにも反映すること。

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更の内容を他の人が見ても分かるように記述する。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルではすぐにマスターに取り込まれ、その後リモートに反映される。しかしプルリクエストでは、リモート上で他の人がマスターに取り込む前にチェックすることが可能となり、バグを事前に発見することが可能となる。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- どの変更内容を取り込むか決めて対象する必要がある。1つを選択して取り込む分には問題はないが、複数を同時に取り込む場合は、実際に書いた人と相談することも重要となる。
